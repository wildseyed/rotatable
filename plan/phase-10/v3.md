notes, effect envelopes). Owner request 2026-09-28: close the last
interaction-model gaps vs the Reactable.

tempo = §3.12 Song Settings; global FX = §3.13 Output panels.

## Execution order

Each batch: implement → deploy → device-verify via REST/e2e → tick →
notebook → commit. Engine batches (2, 3) each need the full jack/sclang/
crone/matron restart (AGENTS.md gotcha 3) — batch engine work together

**Batch 1 — the slider (visual + feel, no engine work):**
- [x] On-block slider indicator: a dot on the glyph rim (second dot,
  distinct from the rotation tick + subtype pictogram) whose position
  shows the E3/slider value — radial distance from center = value
  (mirrors the original's drag-outward-to-lock). Visible at same zoom
  threshold as subtype pictograms; brighter when selected + in ROTATE
- [x] Mapping audit vs spec §3 (already E3 in ROTATE — verify, fix

  lfo = depth, sequencer/midi/tonality/output = none (hide slider dot)
- [x] Feel: K1+E3 = fine adjust (0.2× step) in ROTATE — the original's
  precision-drag equivalent

**Batch 2 — tempo as a table object (Song Settings gap):**
